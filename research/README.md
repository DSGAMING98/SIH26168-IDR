# Research source and reproducibility boundaries

This source snapshot adds the full Python estimator modules, configurations, model,
research tools and tests to the published evidence. Android source remains at
`../technical-evidence/android/android/`. Datasets and private phone traces are not included.

Run from a research checkout containing the original IO-VNBD and Smartphone Decimeter
dataset layouts documented by the adapters. The existing local engineering environment
was used for the reported 293-test run; this newly packaged layout has NOT independently
passed the complete suite. Some historical regression tests and benchmark tools also
need original saved result fixtures (`results/phase5/.../frozen_configuration.json`,
saved scenario outputs, and other phase results). They are not silently replaced by new results.

The causal estimator source is in `src/idr`. `causal_reinitialization.py` and the
optional independent-prior/turning constraints are experimental and disabled in frozen settings.

Reproduction tools:

- `tools/run_phase5_benchmarks.py --scenario S1_10_STEADY --output-dir <new-directory>`
- `tools/finalist_error_budget.py`
- `tools/finalist_initialization_ablation.py --suite initialization`
- `tools/finalist_initialization_ablation.py --suite feedback_bias`
- `tools/finalist_initialization_ablation.py --suite turn_constraint`
- `tools/run_phase8_validation.py --output <new-directory>`
- `tools/finalist_cross_device_candidate.py`
- `tools/finalist_report.py`

Candidate cross-device outputs use the existing evaluator's historical column names
(`C2_FROZEN_PHASE5_EKF`, `C3_FROZEN_PHASE5_HYBRID`) for compatibility. In the candidate
directory those columns represent candidate initialization, NOT the frozen baseline.
Do not use its autogenerated historical judge-summary wording as current evidence.

Public accuracy claims remain baseline 0/4 below 10%; exploratory candidate 1/4.
Training/scaler/checkpoint are unchanged. Benchmark windows now inform engineering;
new independent routes and devices are needed for blind validation.
